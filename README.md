# Draphos Prospect 6.0
Publique os quatro arquivos na raiz do GitHub Pages. Sem API ou serviços de mapas. Escolha a IA, clique em pesquisar, cole o prompt copiado na conversa e envie. Copie o JSON da resposta para o painel e importe. Se a IA não encontrar resultados ou atingir limite, clique em Trocar IA. O rodízio é acionado manualmente: o navegador não consegue detectar créditos ou ler conversas externas. Confira fontes, telefones e mensagens antes de enviar. Os dados ficam no armazenamento local do mesmo endereço do site; exporte CSV para backup. Não há promessa de pesquisa ilimitada ou automática entre plataformas.
