# Draphos Prospect 10 — Mensagens
Publique index.html, app.js e style.css no GitHub Pages. Não precisa de API. A leitura de PDF usa PDF.js via CDN e requer internet. PDFs de imagem não são reconhecidos. Formato recomendado: uma linha por empresa, com Empresa | Cidade | Telefone | Endereço | Situação do site | Elogio verificável. Revise os dados e as mensagens. O botão WhatsApp abre a conversa, não envia automaticamente. Contatos são salvos no navegador. Esta edição usa uma nova chave de armazenamento.
