# Draphos Prospect 8.0 — Extensão Chrome

1. Extraia o ZIP em uma pasta.
2. No Chrome, abra chrome://extensions.
3. Ative Modo do desenvolvedor.
4. Clique Carregar sem compactação e selecione a pasta com manifest.json.
5. Abra o Draphos pelo ícone de extensões.
6. Escolha segmento, cidade e IA. Clique Pesquisar com IA, cole o prompt (Ctrl+V) e envie. Ative pesquisa web se disponível.
7. Selecione somente o array JSON da resposta; clique com o botão direito e escolha Importar para Draphos Prospect. Alternativamente copie e cole no campo de importação do painel.
8. Revise fontes e dados antes de enviar mensagens.

Sem API ou credenciais na extensão. As plataformas podem exigir login, limitar pesquisas ou não oferecer busca web no plano gratuito. Não há envio automático de prompts, detecção automática de créditos ou captura automática de conversas. O rodízio é manual. Os contatos ficam no armazenamento local do painel da extensão e não migram automaticamente do GitHub Pages.
