# Draphos Prospect 11
Publique todos os arquivos na raiz do GitHub Pages. Selecione o PDF e clique Ler PDF. O leitor tenta interpretar tabelas com cabeçalhos Empresa/Estabelecimento, Cidade, Telefone, Endereço e Situação; também aceita linhas com |. Revise os dados e mensagens. PDFs digitalizados não são suportados. O leitor PDF.js usa CDN e internet; se a tabela não for reconhecida, veja o texto extraído e ajuste os campos. Sem API. WhatsApp abre a conversa para envio manual. Contatos existentes da versão 10 são preservados no mesmo domínio.
