# Draphos Prospect Free 2.0
Sem API, cartão ou servidor. Abra index.html ou publique os três arquivos na raiz do repositório GitHub Pages. Pesquise no Google Maps em uma nova aba e cadastre manualmente informações comerciais públicas. Não extrai resultados automaticamente. Revise mensagens antes de enviar; não declare indicação pessoal inexistente. Os dados ficam no navegador e podem ser exportados em CSV. Limpar dados do navegador pode apagar os registros. A versão Free usa armazenamento separado da versão anterior. Não envie mensagens em massa ou insistentes.
