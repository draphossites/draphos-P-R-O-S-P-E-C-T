# Draphos Prospect
1. Extraia o ZIP e envie index.html, style.css e app.js para a raiz de um repositório GitHub.
2. Settings > Pages > Deploy from a branch > main / root. Abra o endereço publicado.
3. No Google Cloud Console, crie projeto, habilite faturamento, Maps JavaScript API e Places API (New). Crie chave com restrição de websites (seu domínio GitHub Pages) e restrição às APIs necessárias. Configure cotas. Nunca publique a chave no repositório.
4. Abra Configurar Google e informe a chave na sessão. Pesquise nicho e cidade. A busca retorna até 20 resultados; consultar avaliações é opcional e pode gerar cobrança adicional.
5. Sem chave, há exemplos fictícios. Adicione contatos próprios manualmente para persistir a carteira. Resultados do Google e suas etapas são temporários; não são exportados nem armazenados. Confira as condições de uso do Google Maps e a LGPD antes de uso comercial; respeite pedidos de não contato e não automatize disparos. Não afirme indicação inexistente. Telefone comercial não garante WhatsApp; confirme antes de enviar.
Documentação: https://developers.google.com/maps/documentation/javascript/place-search ; https://developers.google.com/maps/documentation/places/web-service/policies
